# 07 · 发版与归档

> 前置：**用户看屏通过**（[05-真机验收](05-真机验收.md) 六场景全过）。⛔ 没有这句话不许发。

## 一、发版链（顺序固定）

| 步 | 动作 | 判据 |
|:--:|:--|:--|
| 1 | bump `plugin.json` ＋ `package.json` → **1.0.37**（两处同值） | 版本真源 = `plugin.json` |
| 2 | `CHANGELOG.md` 顶部加 `## v1.0.37（YYYY-MM-DD）` 段 | 市场详情页"更改日志"取它 |
| 3 | `npm run verify`（九段）· `npm run test` · `npm run build` | 全绿 |
| 4 | `git add -A && git commit -m "feat: serial-monitor 1.0.37——门外 AI 契约补齐（状态可信/缓冲查询/等待原语/复位）"` | 直连前缀 |
| 5 | `git -c http.proxy=http://127.0.0.1:7890 -c https.proxy=http://127.0.0.1:7890 push origin main` | 推成功 |
| 6 | `LINKDESK_GITHUB_TOKEN=$(gh auth token) npm run publish -- --yes` | 前置断言：HEAD 已推 ＋ 工作区干净 |
| 7 | `git pull`（publish 在远端更新了仓内 `marketplace.json`） | 否则下次 publish 撞断言 |
| 8 | **官方目录外科式收录**：`E:\linkdesk-plugins\linkdesk-marketplace\marketplace.json` | 只换自己那行 ＋ `versions` 插一条 ＋ 顶层 `updatedAt` |
| 9 | 收录提交并推送（代理同上） | 用户软件里才看得到 |
| 10 | **不随包 ⇒ 无 `sync:bundled`** | 串口监视器 `seed:false` |
| 11 | `npm run sync:plugin-agents`（在壳仓跑） | **最后一步**（版本变了 AGENTS.md 会漂） |
| 12 | 插件仓提交再生的 `AGENTS.md` ＋ 推送 | — |

## 二、官方目录收录注意（外科式）

- ⛔ **不要全量重生成**——会抹掉别的插件的历史行；
- 只改：`plugins[]` 里 `id === "serial-monitor"` 那一条；
  - `version` / `downloadUrl` / `size` / `publishedAt` / `readmeUrl` / 图标 URL；
  - `versions` **数组头部插一条**新版本（旧条不动）；
- 顶层 `updatedAt` 更新。
